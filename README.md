I did alot of work learning about roku devices over the winter - and unfortunately lost alot of tools I had on my WSL distro. Now I've only remade a basic CLI 

remote control , and roku_send (ghost typing) . Due to the response on instagram I figured I should probably put them up here on github :)

roku_send 's space bar hasn't been tested and integrated yet , so payloads need to be single string format, no spaces.
